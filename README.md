# Weather Dashboard

## Description
A dynamic weather dashboard that allows users to search for weather conditions in different cities. The application provides current weather data and a 5-day forecast using the OpenWeather API. It features a clean interface with city thumbnails and persistent search history.

## Features
- Real-time weather data display
- Current conditions including:
  - Temperature
  - Wind speed
  - Humidity
  - Weather icon
- 5-day weather forecast
- Search history with city thumbnails
- Local storage integration for persistent data
- Responsive design using Bootstrap

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Day.js for date formatting
- OpenWeather API
- Local Storage for data persistence

## Installation
1. Clone the repository
2. Open `index.html` in your browser
3. No additional installation required

## Usage
1. Enter a city name in the search bar
2. Click the search button or press enter
3. View current weather and 5-day forecast
4. Previously searched cities appear as buttons with thumbnails
5. Click on any city in the history to view its weather again

## API Reference
This project uses the OpenWeather API:
- Current Weather Data
- 5 Day Weather Forecast
